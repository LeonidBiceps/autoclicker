# autoclicker

Монорепозиторий с несколькими независимыми продуктами:

- **[`desktop-clicker/`](desktop-clicker/README.md)** — «МультиТул», desktop-автокликер на Electron
  (Windows): мышь/клавиатура, макросы, триггеры по цвету/тексту/картинке, запись экрана и другое.
  Основной платный продукт, есть готовый `.exe` в
  [релизах](https://github.com/LeonidBiceps/autoclicker/releases/latest).
- **[`extensions/`](extensions/README.md)** — шесть расширений для Chrome: `clicker` (браузерная
  версия автокликера, платный Pro), `distraction-blocker`, `text-counter`, `price-tracker`,
  `ai-summarizer`, `ai-rewriter`.
- **[`games/`](#игры)** — портфель HTML5-игр для Яндекс Игр на общем движке (`packages/engine`,
  `packages/ysdk`).

`desktop-clicker` и `extensions/clicker` — один и тот же автокликер в двух формах (десктоп и
браузер), с общим форматом лицензионного ключа. Остальное — независимые побочные проекты в том же
репозитории.

## Игры — быстрый старт

```bash
npm install
npm run dev -- merge2048
```

Откроется дев-сервер. Yandex SDK подменяется моком автоматически: реклама реально занимает экран и
время, сейвы переживают перезагрузку, лидерборд ранжирует. Аккаунт разработчика для этого не нужен.

### Команды

| Команда | Что делает |
| --- | --- |
| `npm run list` | что есть в портфеле |
| `npm run new -- <slug> "Название"` | новая игра из шаблона |
| `npm run dev -- <slug>` | дев-сервер с моком SDK |
| `npm run assets -- <slug>` | иконка, обложка и скриншоты для карточки |
| `npm run build -- <slug>` | прод-сборка + проверка бюджета и требований платформы |
| `npm run preview -- <slug>` | посмотреть прод-сборку локально |
| `npm run package -- <slug>` | zip, готовый к загрузке в консоль разработчика |
| `npm run check` | типы по всему репозиторию |

Вместо `<slug>` можно передать `--all`, чтобы обработать весь портфель.

### Структура

```
desktop-clicker/    МультиТул — desktop-автокликер на Electron
extensions/          6 расширений для Chrome (clicker и другие)
packages/ysdk        обёртка над Yandex Games SDK + мок платформы
packages/engine      цикл, ввод, canvas, синтезированный звук, воронка событий
games/<slug>         игры
templates/game        заготовка, из которой создаются новые игры
tools/cli.mjs         вся автоматизация игрового портфеля
```

### Что уже есть

**`packages/ysdk`** — единственное место, где код игры соприкасается с платформой. Все вызовы не
бросают исключений и гарантированно резолвятся: у платформы бывают колбэки рекламы, которые не
приходят никогда. Полноэкранная реклама сама соблюдает прогрев и кулдаун, сейвы схлопываются в один
запрос и дописываются при уходе со вкладки, есть оффлайн-резерв в `localStorage`.

**`packages/engine`** — цикл с паузой (вкладка + реклама) и ограничением дельты, свайпы с порогом в
долях экрана, canvas с корректным DPR, звук, синтезируемый на WebAudio (ноль байт ассетов),
модальные окна и таблица лидеров, частицы/кольца/тряска экрана/звёздный фон для визуальной
«сочности», локализация RU/EN, компактный формат больших чисел, отправка событий воронки.

**`tools/store-art`** — генератор иконки, обложки и скриншотов карточки: рисует их кодом (без
внешних изображений) и для игр с канвасом снимает скриншоты из настоящего игрового поля, а не
рисует их отдельно.

### Игры

- **`games/merge2048`** — 2048: свайпы и клавиатура, откат хода (3 бесплатных, дальше за рекламу),
  продолжение после проигрыша за rewarded, лидерборд, облачный сейв, RU/EN.
- **`games/starfarm`** — Космоферма, idle-кликер: 6 построек, офлайн-доход (растёт с перком, до
  100%), перезапуск за звёздную пыль с деревом из 6 постоянных перков, золотые метеориты как
  активная механика поверх пассивного дохода, частицы и тряска экрана на крупных событиях.
- **`games/gems`** — Самоцветы, бесконечный match-3: своп тапом или драгом, каскады с растущим
  множителем очков, подсказка хода при бездействии, автоматическая бесплатная пересборка тупикового
  поля (не за рекламу — это не вина игрока), удвоение очков и ручное перемешивание за rewarded.
- **`games/towerstack`** — Башня: роняешь блоки на движущуюся башню, стараясь попасть максимально
  ровно — чем выше, тем быстрее.
- **`games/astroassault`** — Астроштурм: отражаешь волны врагов, прыгаешь по платформам и
  прокачиваешься между боями.
- **`games/lovestory`** — Клуб Свиданий: выбираешь, с кем из персонажей продолжить историю.
