# autoclicker — МультиТул

**МультиТул** — автоматизация под Windows: автокликер, макросы, бинды, триггеры. Работает в любом
окне/игре, не только в браузере.

## Что умеет

- **Клик** — по курсору, в фиксированной точке или по последовательности точек; мышь и клавиатура;
  интервал с разбросом или полностью без ограничений (**турбо-режим**, включая **нативный
  турбо** — свой модуль на Rust в обход JS, быстрее обычного турбо на ~40-45%).
- **Макросы** — запись реальных кликов/нажатий и повтор.
- **Триггеры** — клик только когда: цвет пикселя совпал, на экране появился нужный текст (OCR) или
  картинка-образец, активно нужное окно.
- **Наблюдатель значений** — следит за любым числом/текстом на экране (цена, счёт, таймер) и
  уведомляет при изменении, независимо от того, работает ли сам кликер.
- Запись экрана, буфер обмена с историей, плавающие заметки, автозагрузка, антиАФК, уведомления в
  Telegram, профили настроек, расписание отложенного/повторяющегося запуска.

Подробности и полный список — в [desktop-clicker/README.md](desktop-clicker/README.md).

## Бесплатно и Pro

Бесплатная версия — лимит 5000 кликов за один запуск, только курсор/одна точка. **Pro** снимает
лимит и открывает макросы, последовательности точек, триггеры, запись экрана, OCR, турбо-режим и
остальное — по лицензионному ключу с ограниченным сроком (как подписка).

Как получить ключ: задонать от 200 ₽ на
[donationalerts.com/r/leonidbiceps111](https://www.donationalerts.com/r/leonidbiceps111), указав
свою почту в комментарии к донату — ключ пришлют на неё. Один ключ работает и в desktop-приложении,
и в браузерном расширении.

## Скачать

- **Windows-приложение** — готовый `.exe` в [релизах](https://github.com/LeonidBiceps/autoclicker/releases/latest).
- **Расширение для Chrome** — та же автоматизация во вкладке браузера, урезанный набор функций (без
  макросов/записи экрана/части триггеров). Подробности в [extensions/README.md](extensions/README.md).

## Структура репозитория

- [`desktop-clicker/`](desktop-clicker/README.md) — исходники Windows-приложения.
- [`extensions/`](extensions/README.md) — шесть расширений для Chrome (`clicker` — браузерная версия
  МультиТула, плюс пять независимых утилит: `distraction-blocker`, `text-counter`, `price-tracker`,
  `ai-summarizer`, `ai-rewriter`).
