# Расширения для Chrome

Шесть независимых Manifest V3 расширений. Без сборки — грузятся как есть.

## Как загрузить и проверить

1. `chrome://extensions`
2. Включить «Режим разработчика» (правый верхний угол)
3. «Загрузить распакованное расширение» → выбрать папку конкретного расширения (например, `extensions/clicker`)
4. Повторить для каждого расширения по отдельности — у каждого своя папка и свой manifest

После правок кода жми «Обновить» (иконка circular-arrow) на карточке расширения в `chrome://extensions`.

## Готовый .zip для чужих пользователей (`clicker`)

Разработчику код нужен как папка (см. выше), а обычному покупателю — нет. Для `clicker` есть
готовый архив в [релизах](https://github.com/LeonidBiceps/autoclicker/releases/latest)
(`Autoclicker-Extension-X.Y.Z.zip`) — скачать, распаковать в любую папку, «Загрузить распакованное
расширение» на эту папку. Собирается через `node extensions/clicker/scripts/build-zip.cjs` —
явный allowlist файлов (**никогда** не включает `license-tools/` с приватным ключом — иначе любой
покупатель смог бы сам штамповать себе Pro-лицензии). При новом релизе — пересобрать и залить через
`gh release upload vX.Y.Z extensions/clicker/dist/Autoclicker-Extension-X.Y.Z.zip`.

Расширение само проверяет версию против последнего релиза на GitHub при открытии страницы настроек
и показывает баннер, если вышло обновление — но переустановка всё равно ручная (Chrome Web Store не
используется, автообновления нет).

## Список

| Папка | Что делает | Нужен API-ключ? |
| --- | --- | --- |
| `clicker` | Автокликер: мышь/клавиатура, точка/последовательность точек, глобальные хоткеи, автостоп, скачивание картинок по правому клику | нет |
| `distraction-blocker` | Прячет Shorts/Reels на YouTube/Instagram/Facebook, авто-отклоняет cookie-баннеры, считает заблокированное | нет |
| `text-counter` | Счётчик символов/слов/времени чтения + лимиты под форматы + плотность ключевого слова | нет |
| `price-tracker` | Читает цену со страницы товара (в т.ч. Wildberries — свой разбор карточки, плюс предупреждение о накрученных «старых ценах»), хранит историю со спарклайном, уведомляет о падении ниже порога. В поиске Wildberries — бейдж «₽ за 100г/100мл/шт» на каждой карточке, чтобы сравнивать реальную выгоду между разными фасовками | нет |
| `ai-summarizer` | Кнопка «TL;DR» — сводка через Claude API, 3 формата на выбор, кеш на странице | да, Anthropic |
| `ai-rewriter` | Выдели текст — переписывает под тон (4 пресета + свой), превью «было→станет» перед заменой | да, Anthropic |

## Про API-ключ (ai-summarizer, ai-rewriter)

Клик по иконке расширения в панели инструментов открывает страницу настроек — туда вставляется
свой ключ с [console.anthropic.com](https://console.anthropic.com/settings/keys). Ключ хранится
только в `chrome.storage.local` этого браузера и уходит только на `api.anthropic.com` — никакого
своего сервера нет, поэтому это работает как персональный инструмент, а не как продукт для
раздачи чужим пользователям (иначе ключ пришлось бы прятать за бэкендом).

## Известные ограничения (MVP, не баги)

- **`clicker`**: панель по умолчанию полностью скрыта на каждом новом сайте — открывается кнопкой
  «Показать панель» в popup расширения. У открытой панели два разных действия: «─» сворачивает её в
  маленький значок на странице (разворачивается обратно кликом по значку), «✕» закрывает полностью —
  открыть обратно можно только через popup. Пока кликер активен,
  в левом верхнем углу любой страницы горит маленькая зелёная точка (клик по ней — тоже стоп) —
  так видно, что автокликер работает, даже когда панель скрыта. Все настройки по умолчанию (скорость,
  действие, хоткей, автостоп) — в отдельной странице настроек (кнопка «Все настройки →» в popup или
  правый клик по иконке → «Параметры»); сама панель на странице оставляет только то, что нужно
  настраивать по месту (точки, последовательность, быстрый старт/стоп).
  Помимо хоткея на странице есть **глобальные хоткеи через `chrome://extensions/shortcuts`**
  (по умолчанию `Ctrl+Shift+K` старт/стоп, `Ctrl+Shift+L` аварийный стоп) — они срабатывают, даже
  если фокус не на странице. Работает только в основном фрейме страницы (не внутри iframe);
  зафиксированные точки запоминают координаты во вьюпорте — если пролистать страницу, они «съедут»
  относительно контента, нужно выбрать заново. Позиция панели, видимость, режим и точки запоминаются
  отдельно для каждого сайта. Клавиатурный режим не печатает текст в поля ввода — синтетические
  keydown/keyup не эмулируют реальный ввод символов, поэтому он рассчитан на игры и скрипты,
  слушающие нажатия клавиш напрямую, а не на автозаполнение текста.
- **`distraction-blocker`**: Instagram и Facebook часто меняют вёрстку — селекторы для Reels могут
  отвалиться раньше, чем YouTube-часть (там разметка стабильнее). Счётчик заблокированного считает
  приблизительно (по количеству совпавших DOM-элементов), а не по «реальным просмотрам, которых
  избежал» — это ориентир, а не точная метрика.
- **`price-tracker`**: для большинства магазинов работает через `schema.org/Product`, Open Graph
  (`product:price:amount`) или `itemprop="price"` — это покрывает многие крупные магазины, но не
  все. Для Wildberries это не подходит (проверено вживую: сайт ничего из этого не отдаёт, цена
  дорисовывается JS уже после загрузки) — там свой разбор карточки товара по классам
  `priceBlockFinalPrice`/`priceBlockOldPrice`/`productTitle`. **Ozon пока не поддержан** — не
  успел проверить вёрстку вживую (сайт был недоступен из тестового окружения), сработают только
  общие способы выше, если Ozon их отдаёт. Уведомление о падении цены требует, чтобы браузер (и
  сама вкладка с товаром) хоть иногда открывались вручную — WB и Ozon активно блокируют
  автоматические фоновые запросы (антибот-защита), поэтому фоновой проверки без открытой вкладки
  здесь принципиально нет.
- **Бейдж «цена за единицу»** (поиск Wildberries): вес/объём/количество достаётся из названия
  товара регуляркой ("1 кг", "500 г", "3 шт" и т.п.) — это эвристика по тексту, не структурированные
  данные. Если продавец не указал фасовку в названии или написал её нестандартно — бейджа не будет
  (осознанно: лучше промолчать, чем посчитать неверно). На «орехи» в тесте сработало на 14 из 15
  карточек. Также обновляется на переходах внутри WB без перезагрузки страницы (SPA) — страница
  поиска пересканируется автоматически при смене запроса или подгрузке новых карточек при скролле.
- **`ai-summarizer`**: кеш сводки привязан к точному URL страницы и выбранному формату — если статья
  на странице изменилась, а URL остался тот же, кеш это не заметит; жми «Обновить» вручную.
- **`ai-rewriter`**: замена текста в React/Vue-контролируемых полях (где значение перезаписывается
  фреймворком) может не подхватиться — нативные `<textarea>`/`contenteditable` работают надёжно.

## Публикация в Chrome Web Store

Не входит в этот шаг — нужен свой аккаунт разработчика (разовый платёж $5) и ручное прохождение
формы листинга. Когда решишь публиковать что-то из списка — скажи, помогу собрать иконки/скриншоты
и пройти чек-лист требований Web Store.

## Монетизация — что уже в коде, а что нужно сделать руками

Chrome Web Store больше не продаёт расширения напрямую (Google убрал платные items в 2020), так что
оплата всегда идёт через сторонний сервис. Код готов принимать деньги, но сами аккаунты/программы
я завести не могу — это твои платёжные данные.

- **`price-tracker` → партнёрские ссылки.** В popup есть поле «Партнёрская ссылка»: шаблон вида
  `https://ad.admitad.com/g/xxxxx/?ulp={url}`, `{url}` подставляется автоматически. Что нужно сделать
  самому: зарегистрироваться в партнёрской программе (Admitad, ePN, Amazon Associates и т.д.),
  получить свой шаблон/tracking-ID оттуда и вставить в это поле. Без регистрации поле просто не
  используется — ссылки открываются как обычно.

- **`clicker` → платный Pro, без Gumroad/Stripe/PayPal.** Раз оплата из России через них не проходит,
  сделали полностью офлайновую схему: деньги — прямым переводом (СБП/карта), лицензия проверяется
  в самом расширении криптографически (ECDSA P-256, Web Crypto API), без единого запроса в
  интернет. Это же играет роль «подписки» — в ключ зашит срок действия, истёк → доступ пропадает,
  продлил → выдал новый ключ.

  **Что сейчас входит в Pro:**
  - без лимита кликов за один запуск (бесплатная версия останавливается через 5000 кликов — нужно
    заново жать «Старт»)
  - последовательность точек (клик по очереди в нескольких местах)
  - разброс позиции клика (случайное смещение в заданном радиусе)
  - профили настроек (сохранить/применить пресет под конкретный сайт/игру)
  - экспорт/импорт настроек и профилей между компьютерами

  **Как это устроено** (всё уже в `extensions/clicker/license-tools/`, публичный ключ вшит в общий
  `license.js`, которым пользуются и панель на странице, и настройки, и popup):
  1. `node generate-keypair.js` — запускается один раз, создаёт пару ключей. Приватный ключ
     (`private-key.json`) остаётся только у тебя локально (публичный уже вшит в код — это
     безопасно, подписывать лицензии может только тот, у кого приватный ключ, то есть ты).
  2. После оплаты (перевод на карту/СБП, донат — как договоритесь с покупателем) генерируешь ключ:
     `node generate-license.js "имя или @telegram покупателя" 30` (число — на сколько дней, это и
     есть длительность «подписки»). Скрипт выводит готовый ключ — просто скопировать и отправить
     покупателю. Для desktop-версии (см. `desktop-clicker/`) можно четвёртым аргументом передать ID
     компьютера покупателя — тогда ключ привяжется к его железу и не сработает, если он передаст его
     кому-то ещё (в браузерном расширении такая привязка невозможна из-за песочницы).
  3. Покупатель вставляет ключ в настройках расширения (секция «Pro») — открывается
     последовательность точек и разброс позиции клика. Никакой сети, никакого твоего сервера —
     расширение само проверяет подпись и срок годности локально.
  4. `node verify-license.js "<ключ>"` — проверить ключ перед отправкой, если хочешь убедиться, что
     всё подписалось верно.

  Уже сгенерированная пара ключей лежит на этом компьютере — если пересобираешь проект на другой
  машине, не потеряй `license-tools/private-key.json` (без него не выпустить ни одного нового
  ключа, а те, что уже выданы, продолжат работать, пока их срок не истечёт).

Партнёрскую программу (Admitad/ePN) для `price-tracker` по-прежнему нужно завести самому — это
регистрация, которую я сделать не могу, но она в отличие от Gumroad работает из России.
