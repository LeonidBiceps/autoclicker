Автокликер — настройки

Это настройки по умолчанию для новых вкладок. Точку клика, последовательность точек и видимость панели каждый сайт запоминает отдельно — их можно менять прямо в плавающей панели на странице.

Desktop-версия

Этот же автокликер есть и вне браузера — работает в любой программе и игре Windows, не только на вкладке Chrome: последовательность точек, запись макросов, глобальные хоткеи вне браузера, автозапуск с Windows. Один лицензионный ключ открывает Pro в обеих версиях.

Pro

Бесплатная версия. Pro открывает последовательность точек и разброс позиции клика.

Проверяется офлайн, без сети — ключ либо подписан правильно, либо нет.

Скорость

Чтобы клики не шли идеально равномерно — небольшая случайность в тайминге.

Случайное смещение точки клика в этом радиусе. 0 — кликать точно в заданное место.

Действие

Space

Не печатает текст в поля ввода — только события нажатия клавиши, для игр и скриптов, которые слушают их напрямую.

Хоткеи

Работает, пока фокус на странице (не в текстовом поле). Esc всегда останавливает, независимо от этой настройки.

Работают даже если фокус не на странице (например, в адресной строке). Назначены по умолчанию: Ctrl+Shift+K — старт/стоп, Ctrl+Shift+L — аварийный стоп. Поменять сочетания можно в открывшейся странице.

Автостоп

0 — без ограничения. В бесплатной версии есть свой потолок: 5000 кликов за один непрерывный запуск, даже если тут стоит 0 — нужно будет нажать «Старт» ещё раз. Pro снимает этот потолок.

0 — без ограничения.

Профили Pro

Сохрани текущие настройки скорости/действия/автостопа под именем — быстро переключаться между разными сайтами/играми, не перенастраивая всё заново.

Экспорт / импорт Pro

Перенести настройки и профили на другой компьютер (лицензионный ключ в файл не попадает — при переносе его нужно ввести заново).
