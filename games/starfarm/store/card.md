## Русский

**Название**

```
Космоферма
```

**Короткое описание** (~100 символов)

```
Стройте энергетическую империю. Ферма работает, даже когда вы закрыли игру.
```

**Полное описание**

```
Нажимайте на реактор, стройте генераторы, наблюдайте, как растёт добыча
энергии — и возвращайтесь завтра, чтобы забрать то, что накопилось без вас.

Что есть внутри:
• Шесть построек — от солнечной панели до червоточины
• Перезапуск за звёздную пыль: постоянные бонусы, которые не сгорают
• Дерево перков — прокачивайте силу клика, добычу, офлайн-доход и удачу
• Золотые метеориты — лови их кликом ради бонусов
• Офлайн-доход — ферма считает, сколько заработала, пока вас не было
• Таблица лидеров и облачное сохранение

Заходить на пять минут или на час — прогресс не теряется в любом случае.
```

**Теги**

```
кликер, idle, тайкун, космос, таймкиллер, казуальная, перезапуск, офлайн
```

**Категории**: казуальные, кликеры

**Возрастной рейтинг**: 0+

**Язык**: русский, английский

## English

**Title**

```
Star Farm
```

**Short description**

```
Build an energy empire. The farm keeps running after you close the game.
```

**Full description**

```
Tap the reactor, build generators, watch output climb — then come back
tomorrow to collect what piled up while you were away.

Inside:
• Six buildings, from solar panels to wormholes
• Restart for stardust: permanent bonuses that never go away
• A perk tree — upgrade tap power, output, offline earnings, and luck
• Golden meteors — tap them for bonuses
• Offline earnings — the farm tracks what it made while you were gone
• Leaderboard and cloud save

Drop in for five minutes or an hour — progress never resets on its own.
```

**Tags**

```
clicker, idle, tycoon, space, time killer, casual, prestige, offline
```

## Ассеты

| Файл | Размер | Назначение |
| --- | --- | --- |
| `icon-512.png` | 512×512 | иконка |
| `cover-800x470.png` | 800×470 | обложка каталога |
| `screenshot-1..3-1280x720.png` | 1280×720 | скриншоты |

Скриншоты — стилизованный мокап интерфейса, не буквальный снимок страницы:
интерфейс фермы целиком на DOM, а не на канвасе, снять с него «живой» кадр
тем же способом, что и у 2048/Самоцветов, неоткуда. **Сверьте размеры с
требованиями в консоли перед загрузкой.**

Пересобрать:

```bash
npm run assets -- starfarm
```
